# Intro

In the spirit of DHH's proclamation that Rust is a great language to
write code in as long as you don't have to read it, I present a
vibe-coded clone of rcirc in Rust.

# Usage

You run it in a terminal.

It clones a shallow set of emacs keybindings and attempts to be a full
clone of rcirc within that scope. I've diverged in a few ways from
rcirc.el where I thought it made sense.

It's a work-in-progress.

# Model Used

I'm using Deepseek v4.1 flash.
